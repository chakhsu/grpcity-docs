# gRPC Reflection

`gRPCity`'s server speaks the [`gRPC Server Reflection Protocol`](https://github.com/grpc/grpc/blob/master/doc/server-reflection.md), so tools like Postman or `grpcurl` can introspect your service over the wire without a local copy of the `.proto` files.

### Usage

Build a reflection service from the loader and inject it into the server:

```js {3,4}
const server = await loader.initServer()

const reflection  = await loader.initReflection()
server.inject(reflection)
```

### Unary Call

We use the `example/reflection/helloworldServer.js` in `gRPCity` as an example of a `Unary Call`.

```bash filename="Terminal"
node example/reflection/helloworldServer.js
start: localhost:9098
```
